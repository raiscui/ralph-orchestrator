# 任务计划：TUI 的 mdfried 风格渲染（Big Headers + 图片）

## 目标
让 Ralph 的 TUI 输出视图尽可能接近 `mdfried` 的“deep fry”效果：

- Markdown 标题（至少 H1/H2/H3）在支持图形协议的终端里呈现为“更大”的标题
- 可选：支持 Markdown 图片语法 `![]()` 的内联预览（终端支持时）
- 在不支持图形协议的终端里，必须有稳定的降级（不崩溃、可读）
- 不影响现有 event parsing（stdout-only）与并行 supervisor 的稳定性

## 方案（至少二选一）

### 方案 A：不惜代价，最接近 mdfried（推荐）
- 引入 `ratatui-image`，接入它的协议探测与渲染：
  - Kitty / iTerm2 / Sixel（以及 halfblocks/Chafa 降级）
- 为输出视图引入“富块渲染”：
  - 文本块（现有 Line/Span）
  - 图片块（StatefulImage / Image）
- Big Headers：把 H1/H2/H3 渲染成图片/缩放文本（取决于终端能力）
- 可选：支持 `![]()` 图片下载/缓存/渲染（带大小上限与白名单策略）

### 方案 B：先能用，后面再接近 mdfried
- 不做真实图片协议。
- 仅用“ASCII 大字/figlet 风格”模拟标题放大（完全文本）。
- 优点：实现快、无图形协议坑。
- 缺点：视觉效果与 `mdfried` 差距仍然很大，不符合你选的 B 目标。

> 你已选择：方案 A。
