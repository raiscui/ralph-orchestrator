# 任务计划: tui-markdown-rendering（OpenSpec apply 实现）

## 目标
让 Supervisor TUI 的输出视图默认渲染 AI code agent 的 Markdown（至少 h1/h2、引用、代码块），并新增 `--plain` 可一键关闭渲染回退纯文本。

## 方案（至少二选一）

### 方案 A：不惜代价，最佳方案（更一致）
- 让“串行 TUI（TuiStreamHandler）”与“并行 Supervisor TUI（ParallelTuiState）”都复用同一个“Markdown 渲染/纯文本”开关与渲染函数。
- 默认渲染 Markdown；`--plain` 关闭渲染。
- 优点：行为一致、测试可共享；缺点：涉及的模块较多，需要把开关贯通到两条路径。

### 方案 B：先能用，后面再优雅（改动更小）
- 只在并行 Supervisor TUI 内实现 Markdown 渲染与 `--plain`（满足你最在意的 TUI 输出）。
- 串行 TUI 暂不动（仍保持现状）。
- 优点：改动集中；缺点：两条 TUI 路径渲染行为可能不一致。

**本次选择：方案 A**（原因：本项目已存在 `termimad` 渲染与 `TuiStreamHandler`，更适合“改良胜过新增”，并避免双实现分叉。）

## 遇到错误
- [错误] `ParallelTuiState::append_output` 内既持有 `instances.get_mut(...)` 的可变借用，又调用了需要借用 `&self` 的渲染函数，触发 Rust 借用检查错误 `E0502`。
  - [决议] 把渲染函数改为“纯函数参数”（传入 `MarkdownRenderMode` + job 引用），避免跨字段的借用冲突。
